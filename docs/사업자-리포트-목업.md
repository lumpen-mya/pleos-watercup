# 사업자 리포트 화면 목업

> **목업 · 예시 데이터(실제 측정값 아님) · 앱에 아직 없는 확대 계획**
>
> 택시·카셰어링·법인 차량 운영사가 볼 주간 승차감 리포트의 화면 구상이다. 아래의 기사명·차량번호·회사명·숫자는 모두 지어낸 예시이며, 실제 사람·회사·측정과 관계없다.
> 지금 앱은 주행 기록을 기기 안에만 저장하고 밖으로 보내지 않는다. 이 리포트를 만들려면 기사 동의를 받은 기록 수집, 기사·차량 구분값, 민감도·보정값·뒷좌석 탑승 여부 기록, 30회 넘는 보관(지금은 최근 30회만 남김), 운영사 화면을 새로 개발해야 한다.

리포트의 숫자는 지금 앱이 주행마다 이미 남기는 값(주행 거리·시간, 쏟은 횟수, 원인별 횟수)을 모아서 계산한다고 가정한다. 기사별·차량별 표에는 지금 기록에 없는 기사·차량 구분값이 더 필요하다.

## 1. 요약 (예시 운수사 · 예시 주간)

```
┌──────────────────────────────────────────────────────────────┐
│  예시운수 주간 승차감 리포트          예시 주간 (7일)        │
├──────────────────────────────────────────────────────────────┤
│  운행 차량 12대 · 기사 18명 · 주행 1,240회                   │
│                                                              │
│  주행당 쏟은 횟수   1.8회   (지난주 2.3회)   ▼ 0.5          │
│  "편안한 차량" 기준 달성   7 / 12대                          │
│  가장 많은 원인    가속 페달 급히 떼기 (42%)                 │
└──────────────────────────────────────────────────────────────┘
```

## 2. 기사별

| 기사 | 주행 수 | 주행당 쏟은 횟수 | 지난주 대비 | 가장 많은 원인 | 코칭 한마디 |
|---|---:|---:|---:|---|---|
| 기사 A | 82 | 0.9 | ▼ 0.4 | 급제동 | 정지 직전에 브레이크를 살짝 풀어 주세요 |
| 기사 B | 75 | 1.4 | ▼ 0.2 | 가속 페달 급히 떼기 | 가속 페달은 천천히 떼어 주세요 |
| 기사 C | 91 | 3.6 | ▲ 0.3 | 가속 페달 급히 떼기 | 가속 페달은 천천히 떼어 주세요 |
| 기사 D | 64 | 2.1 | ▼ 1.0 | 급핸들 | 핸들은 미리, 천천히 돌려 주세요 |

코칭 한마디는 앱이 주행 중·도착 리뷰에서 이미 쓰는 원인별 문구를 그대로 쓴다.

## 3. 차량별

| 차량 | 차종(예시) | 주행 수 | 주행당 쏟은 횟수 | "편안한 차량" 기준 |
|---|---|---:|---:|---|
| 차량 01 | 전기 세단 | 140 | 1.1 | 달성 |
| 차량 02 | 전기 세단 | 121 | 1.9 | 달성 |
| 차량 03 | 전기 SUV | 133 | 3.2 | 미달 (가속 페달 급히 떼기 54%) |
| 차량 04 | 하이브리드 세단 | 98 | 0.7 | 달성 |

"편안한 차량" 기준은 예시로 "주 50회 이상 주행 + 주행당 쏟은 횟수 2.0회 이하"로 둔다. 실제 기준값은 실차 데이터와 승객 반응을 보고 정할 계획이며 아직 정해지지 않았다. 쏟은 횟수는 민감도와 동승자 확인 보정값에 따라 달라지므로, 기사·차량 간 비교는 넘침 기준을 하나로 고정하고 승객이 탄 주행만 집계한다는 전제다.

## 4. 원인 분포 (전체 주행)

```
가속 페달 급히 떼기  ██████████████████████  42%
급제동              ████████████            23%
급핸들              ████████                15%
급가속              ██████                  12%
과속방지턱          ████                     8%
```

원인은 기본 4종 + 길 안내 중 과속방지턱이다. 과속방지턱은 길 안내 중인 주행에서만 집계되며 실경로 확인은 2차 개발이다.

회생제동(가속 페달 급히 떼기) 비중이 높으면 리포트가 "회생제동 단계를 한 단계 낮춰 보세요" 같은 차량 설정 조언을 함께 띄운다(확대 계획).

## 5. 주간 추세 (주행당 쏟은 횟수)

```
3.0 ┤  ● 3.0
2.5 ┤        ● 2.7 ● 2.5       ● 2.3
2.0 ┤                    ● 2.1       ● 1.8
1.5 ┤
1.0 ┤
    └──┬─────┬─────┬─────┬─────┬─────┬──
      1주   2주   3주   4주   5주   6주
```

추세는 앱 대기 화면의 주행별 막대 그래프와 같은 값을 주 단위로 묶은 것이다. 앱은 최근 30회 주행만 남기므로 주 단위 추세는 기록 수집이 있어야 나온다.
